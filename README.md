# 💎 SOUMIK ONLINE

Welcome to the official repository for **SOUMIK ONLINE**, a comprehensive web and mobile application platform dedicated to showcasing exquisite jewelry collections and providing seamless online services.

## 🚀 About the Project
SOUMIK ONLINE is designed to offer an elegant, secure, and user-friendly shopping experience. The platform integrates a modern web interface with a robust Android application, ensuring smooth accessibility across all devices.

## ✨ Key Features
* **Cross-Platform Experience:** Responsive web platform and a dedicated Android application.
* **Secure Payments:** Integrated with Razorpay for secure and fast transactions.
* **Real-time Management:** Powered by cloud databases for real-time product updates and reliable user authentication.
* **Admin Tracking:** Efficient order tracking and admin management panel.

## 🛠️ Technologies Used
* **Web Frontend:** HTML, CSS
* **Mobile App:** Android Studio, Kotlin
* **Backend & Database:** Firebase, Supabase
* **Cloud & APIs:** Cloudflare Workers, Razorpay API
